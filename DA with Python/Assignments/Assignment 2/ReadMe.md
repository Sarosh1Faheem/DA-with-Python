# Assignment Overview

## Part - 2: Python Basics — Conditional Statements

Conditional statements are an essential part of Python programming. They allow a program to execute different blocks of code depending on whether a specific condition is **True** or **False**.

The main concepts practiced in this assignment include:

- `if` statements
- `if-else` statements
- `if-elif-else` statements
- Comparison operators
- Arithmetic operators
- Modulus (`%`) operator
- Logical operators
- Nested conditional statements
- User input handling
- Real-world decision-making logic
