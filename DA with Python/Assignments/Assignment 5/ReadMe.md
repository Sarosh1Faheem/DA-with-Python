## Tasks Included in the Assignment

## Task 1: Working with Lists

The program creates a list called `numbers` containing at least **8 integers**.

The program should:

* Print all numbers in the list.
* Calculate and print the sum of all numbers.
* Print only the even numbers.
* Use at least one loop.
* Use conditional statements.
* Display clear output.

### Concepts Practiced — Task 1

* Lists
* `for` loops
* Conditional statements
* Arithmetic calculations
* Even number checking

## Task 2: Dictionary Basics

The program creates a dictionary called `student`.

The dictionary should contain the following keys:

* `name`
* `age`
* `course`
* `marks`

The `marks` key must store a **list of 3 marks**.

The program should:

* Print all keys and their values.
* Calculate the average of the marks using loops.
* Display whether the student **Passed** or **Failed**.
* A student passes when the average marks are **50 or above**.

### Concepts Practiced — Task 2

* Dictionaries
* Lists inside dictionaries
* Loops
* Average calculation
* Conditional statements
* Key-value pairs

---

## Task 3: List of Dictionaries

The program creates a list called `employees`.

Each employee must be stored as a dictionary containing:

* `name`
* `department`
* `salary`

The program should:

* Store a minimum of **3 employees**.
* Print the details of all employees.
* Find the employee with the highest salary.
* Calculate the total salary expense.
* Use comparison logic.
* Use loops to process the employee data.

### Concepts Practiced — Task 3

* Lists
* Dictionaries
* List of dictionaries
* `for` loops
* Comparison logic
* Salary calculations
* Data processing

## Task 4: While Loop with User Input

The program asks the user to enter numbers.

The program should:

* Ask the user to enter numbers.
* Store the entered numbers in a list.
* Continue accepting numbers using a `while` loop.
* Stop when the user enters `-1`.
* Print the complete list after the loop ends.
* Print the largest number.
* Print the smallest number.

The value `-1` is used as the stopping condition and should not be included as a normal number in the list.

### Concepts Practiced — Task 4

* `while` loops
* User input
* Lists
* Conditional statements
* Loop termination
* Maximum and minimum values

## Task 5: Word Frequency Counter

The program asks the user to enter a sentence.

The program should:

* Accept a sentence from the user.
* Convert the sentence into a list of words.
* Use a dictionary to count how many times each word appears.
* Print the word frequency clearly.

For example, the output format should represent word frequencies such as:

* `apple: 3`
* `banana: 2`
* `orange: 1`

### Concepts Practiced — Task 5

* Strings
* String splitting
* Lists
* Dictionaries
* Loops
* Word counting
* Conditional logic
