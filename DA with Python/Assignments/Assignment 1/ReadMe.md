# Assignment 01 — Python Basics: Variable & Operators 

# Assignment  Overview

## Part - 1: Python Basic - Variable & Operators

This assignment is designed to build a strong foundation in Python programming by practicing basic syntax, variables, operators, calculations, and problem-solving techniques. The tasks focus on applying Python concepts to simple real-world and mathematical problems.

----------

# Tasks Included in the Assignment
1. Personal Information Using Escape Sequences

This task focuses on using Python's print() function along with escape sequences such as \n and \t to display personal information in a properly formatted manner.

2. Small Bio Using Variables

This task introduces variables in Python. Different personal details are stored in variables and then displayed using the print() function.

3. Python Operators

This task provides practice with the different types of operators available in Python, including arithmetic, comparison, assignment, logical, and other commonly used operators.

4. Marks and Percentage Calculation

This task focuses on storing marks in separate variables, defining the total marks, and using mathematical operations to calculate the student's percentage.

5. Swapping Two Variables

This task demonstrates how to swap the values of two variables without using a third variable, helping develop an understanding of variable assignment and Python's ability to perform multiple assignments.

6. Circle Area and Circumference

This task applies Python variables and mathematical calculations to determine the area and circumference of a circle using a given radius and the specified value of π.

7. Discount Calculation

This task demonstrates a simple real-world financial calculation by taking an item's price and discount percentage, calculating the discount amount, and determining the final price after applying the discount.

### Overall Learning Objective

Through these seven tasks, the assignment provides practical experience with:

* Python print() function
* Escape sequences
* Variables
* Data and numerical values
* Operators
* Mathematical calculations
* Multiple assignment
* Basic problem solving
* Applying Python to real-world calculations
