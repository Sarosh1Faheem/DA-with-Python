1st Step: Create a Project Directory
2nd Step: Open MS VS via Cmd
3rd Step: initialize Project with Command: "uv init" : Directory via MS VS
4th Step: Create Virtual Environment for the project with command: "uv venv"
5th Step: Activate project with command ".venv\Scripts\activate"


CMD Commands: 
1: uv init
2: uv venv
3: .venv\Scripts\activate.bat
